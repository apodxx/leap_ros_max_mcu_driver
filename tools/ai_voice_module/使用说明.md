# 创乐博 CI1302 AI 语音识别模块：实测使用说明

> 实测环境：Jetson Orin NX（`192.168.0.103`）和 Armbian 6.18 盒子（`192.168.0.107`）
> 结论：**它是一个“USB 复合设备”** —— 内部一个 4 口 HUB，挂了 **CH340 串口** 和 **USB 声卡**。
> 语音识别在模块本地完成，结果从串口以 **5 字节定长帧** 发出来；喇叭/麦克风走 USB 声卡。
> **唤醒词是「小创小创」**（例程里也写成「你好小创」）。

---

## 1. 插上电脑后到底多了什么

`lsusb` 会多出三个设备（拔掉模块三个一起消失，说明 HUB 在模块内部）：

```
Bus 001 Device 004: ID 1a86:8091 QinHeng Electronics USB HUB          <- 模块内部 HUB
Bus 001 Device 005: ID 1a86:7523 QinHeng Electronics CH340 serial     <- 命令/事件通道
Bus 001 Device 006: ID 0c76:161f JMTek, LLC. USB PnP Audio Device     <- 麦克风 + 喇叭
```

对应的系统节点：

| 用途 | Jetson（老内核） | Armbian / 新内核（≥5.16） | Windows |
|---|---|---|---|
| 串口 | `/dev/ttyCH341USB0` | `/dev/ttyUSB0` | `COMx`（需装 CH340 驱动） |
| 声卡 | `arecord -l` 里的 `USB PnP Audio Device` | 同左 | “USB PnP Audio Device” |

声卡能力：**48 kHz / 16 bit / 2 声道，播放 + 录音都有**。
所谓“免驱”指的是声卡是标准 UAC（Linux/macOS 免驱）；**Windows 上串口仍要装 CH340 驱动**，音频不用。

---

## 2. 串口协议（官方例程 + 实机验证）

- 波特率 **115200，8N1**，无流控
- 帧长固定 **5 字节**：`AA 55 CMD DATA FB`

| 帧 | 方向 | 含义 |
|---|---|---|
| `AA 55 03 00 FB` | 模块 → 主机 | **唤醒** |
| `AA 55 02 00 FB` | 模块 → 主机 | **休眠**（约 15 秒无指令） |
| `AA 55 00 01 FB` | 模块 → 主机 | **前进** |
| `AA 55 00 02 FB` | 模块 → 主机 | **后退** |
| `AA 55 00 03 FB` | 模块 → 主机 | **左转** |
| `AA 55 00 04 FB` | 模块 → 主机 | **右转** |
| `AA 55 00 09 FB` | 模块 → 主机 | **停止** |
| `AA 55 01 00 FB` | 模块 → 主机 | 打开串口/上电后的就绪帧 |
| `AA 55 FF 01 FB` | 主机 → 模块 | **播报**（模块“叮”一声，实测有效） |

命令字 `00` + 序号就是“第 N 条命令词”。出厂还有 110+ 条词条，编号表没有外流，用 `listen` 边试边说就能把用到的编号记下来（例如 0x1A 出现过，还没对上词）。

> ⚠️ **打开串口前必须先把 DTR/RTS 置低**，否则 CH340 会把模块复位。官方例程也是这么写的：
> ```python
> ser = serial.Serial(None, 115200, ...)
> ser.rts = False; ser.dtr = False
> ser.port = port; ser.open()
> ```

## 4. 做语音对话（录音 + 识别 + 播报）

模块的麦克风和喇叭就是那块 USB 声卡，所以“在线识别/大模型对话”完全走 ALSA：

```bash
# 录音 3 秒（48k 双声道，实测电平正常：peak≈145 / rms≈30 的安静环境）
arecord -D plughw:CARD=Device -f S16_LE -r 48000 -c 2 -d 3 /tmp/in.wav

# 播放 TTS / 提示音（实测：往声卡放 880Hz，模块麦克风能录到 rms≈13000，喇叭通路正常）
aplay -D plughw:CARD=Device /tmp/tts.wav
```

典型流程（Jetson 上 `xiaozhi-AI.py`、`11.离线部署SenceVoice...` 都是这个套路）：

1. 串口收到 `AA 55 03 00 FB` → 用户喊了「小创小创」；
2. 立刻用 `arecord`/`sounddevice` 录 3~5 秒；
3. 送 SenseVoice/FunASR 做识别 → 大模型 → edge-tts 合成；
4. `aplay` 播回去，再等下一帧（15 秒没命令模块会自己休眠）。

参考实现就在 Jetson：`/home/nvidia/Largemodel/clbAImodule.py`（协议类）和 `16.AI语音模块机器人控制实验.py`。

## 5. ROS 2 集成

`voice_cmd_node.py` 把识别结果直接变成速度指令：

```bash
source /opt/ros/jazzy/setup.bash
cd /root/ai_voice_module
python3 voice_cmd_node.py --ros-args \
  -p port:=/dev/ttyUSB0 -p linear_speed:=0.15 -p angular_speed:=0.5 -p hold:=1.2
```

- `/cmd_vel`：前进/后退/左转/右转各发 1.2 秒后自动归零；“停止”立即归零
- `/voice_command`：`wake` / `sleep` / `forward` / `back` / `left` / `right` / `stop` / `cmdXX`

实测（107，`ros2 topic echo /cmd_vel`）：

```
前进 -> linear.x=0.15        左转 -> angular.z=0.5
1.2 秒后自动补一帧全零       “停止” -> 立即全零
```

> 节点里 `from ai_voice_module import VoiceModule`，所以要 `cd` 到脚本目录再运行（或设 `PYTHONPATH`）。

## 5.1 换到 107（Armbian）上用

可以，而且**之前在 107 上已经跑过**（抓到过 `03 00` / `00 01` / `02 00` 帧）。两台的差别只有两点：

| | Jetson 103 | Armbian 107 |
|---|---|---|
| 串口名 | `/dev/ttyCH341USB0` | `/dev/ttyUSB0`（6.18 内核改了命名） |
| 依赖 | pyserial 3.5 已装 | `python3-serial` 已装（我装好了） |

步骤：

```bash
lsusb | grep -E '1a86|0c76'          # 应看到 HUB / CH340 / USB PnP Audio 三个
python3 ai_voice_module.py ports      # 应列出 /dev/ttyUSB0  USB 1a86:7523（模块内部 HUB）
python3 ai_voice_module.py listen     # 说「小创小创」再下命令
```

几个注意点：

1. **插上后 107 的声卡就是它**（card 0），`arecord -l` 能看到 `USB PnP Audio Device`；
   `aplay -D plughw:CARD=Device xxx.wav` 就从模块喇叭出声。
2. **别和机器人自己的 CH340 搞混**：如果 MCU 也是 CH340，会同时出现两个 `/dev/ttyUSB*`。
   脚本会自动挑“挂在 `1a86:8091` 模块内部 HUB 下面”的那个；也可以 `--port /dev/ttyUSB1` 显式指定。
3. 插拔后端口号可能变（ttyUSB0 ↔ ttyUSB1），用 `python3 ai_voice_module.py ports` 确认一下再起节点。
4. 模块 15 秒没指令会休眠，属正常；`listen` 里会看到 `AA 55 02 00 FB`。

## 6. 踩过的坑

| 现象 | 原因 / 处理 |
|---|---|
| 打开串口后模块像“死”了 | DTR/RTS 拉高把模块复位了；先置低再 open |
| 说半天没帧 | 唤醒词不对（是「小创小创」），或 15 秒无指令已休眠（收到 `02 00`） |
| 找不到 `/dev/ttyUSB0` | 新内核里 CH340 可能叫 `/dev/ttyCH341USB0`；`lsusb` 确认有 `1a86:7523` |
| 分不清哪个 ttyUSB 是模块 | `cat /sys/class/tty/ttyUSB0/device/../../idVendor` 应为 `1a86` |
| 播报没声音 | 声卡被 `pactl` 静音或音量为 0；`amixer -c <card> sset Speaker 80%` |
| 插上没反应（灯不亮） | 换一根**数据线**，有些 Type-C 线只能充电 |
