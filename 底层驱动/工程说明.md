# 麦轮导航完整工程

## 📦 工程说明

这是一个完整的STM32H743麦轮小车导航系统工程，基于参考例程【16】imu陀螺仪改造而成，集成了：

- ✅ 四路TB6612电机驱动（X型麦轮布局）
- ✅ 四路编码器反馈（TIM1/2/3/5编码器模式）
- ✅ IMU660RC六轴陀螺仪（I2C1接口）
- ✅ 麦轮运动学控制（正逆运动学、里程计）
- ✅ PID闭环控制
- ✅ 路径跟踪导航系统
- ✅ 完整的主控制器集成

## 🚀 快速开始

### 1. 打开工程

使用Keil MDK或STM32CubeIDE打开工程：
- **Keil**: 打开 `MDK-ARM/` 文件夹中的 `.uvprojx` 工程文件
- **STM32CubeIDE**: 导入现有项目

### 2. 添加用户驱动到编译

确保在IDE中将以下文件添加到编译列表：

**源文件** (`Drivers/User/Src/`):
- tb6612_motor.c
- encoder.c
- imu660rc.c
- mecanum_kinematics.c
- pid_controller.c
- path_tracking.c
- navigation_controller.c

**头文件路径** (`Drivers/User/Inc/`):
- 在工程设置中添加 `Drivers/User/Inc` 到include路径

### 3. 配置参数

根据你的实际硬件修改 `mecanum_kinematics.h` 中的参数：

```c
#define ROBOT_WHEEL_BASE        0.20f   // 前后轮距(米)
#define ROBOT_TRACK_WIDTH       0.20f   // 左右轮距(米)
#define ROBOT_WHEEL_RADIUS      0.05f   // 轮子半径(米)
#define ENCODER_PPR             1560    // 编码器线数×4×减速比
```

### 4. 编译和烧录

1. 点击编译
2. 连接ST-Link或J-Link
3. 烧录到STM32H743

### 5. 运行

- 上电后LED慢闪3次表示初始化成功
- 3秒后自动开始执行正方形路径
- LED常亮表示正在运行
- 任务完成后LED快速闪烁

## 📝 主程序说明

当前 `main.c` 实现了一个**正方形路径跟踪**示例：

```c
Waypoint_t square_path[] = {
    {0.0f, 0.0f, 0.0f,           0.2f},  // 起点
    {1.0f, 0.0f, 0.0f,           0.2f},  // 前进1米
    {1.0f, 1.0f, 1.5707963f,     0.2f},  // 左移1米，转90度
    {0.0f, 1.0f, 3.14159265f,    0.2f},  // 后退1米，转180度
    {0.0f, 0.0f, -1.5707963f,    0.2f},  // 右移1米，转270度
};
```

小车会自动执行这个路径，完成1米×1米的正方形轨迹。

## 🔧 调试PID参数

PID参数在 `main.c` 中设置：

```c
PathTracker_SetPIDParams(&nav_controller.path_tracker,
    1.5f, 0.01f, 0.2f,   // 位置PID: Kp, Ki, Kd
    2.0f, 0.05f, 0.3f);  // 角度PID: Kp, Ki, Kd
```

**调试步骤**：
1. 从小的Kp开始（如0.5），观察响应
2. 如果响应慢，增加Kp
3. 如果震荡，减小Kp或增加Kd
4. 如果有稳态误差，适当增加Ki
5. 角度控制通常需要更大的Kp值

## 🎯 自定义路径

修改 `main.c` 中的路径点数组：

```c
Waypoint_t my_path[] = {
    // {x(米), y(米), theta(弧度), speed(米/秒)}
    {0.0f, 0.0f, 0.0f, 0.2f},
    {2.0f, 0.0f, 0.0f, 0.3f},
    {2.0f, 2.0f, 1.57f, 0.3f},
    // ... 更多路径点
};

// 启动导航
NavController_StartAutoNav(&nav_controller, my_path,
                          sizeof(my_path) / sizeof(Waypoint_t));
```

## 🐛 故障排查

### IMU初始化失败（LED快速闪烁）
- 检查I2C1连接：PB8(SCL)、PB9(SDA)
- 确认IMU供电和地址设置
- 使用逻辑分析仪查看I2C波形

### 电机不转
- 检查STBY引脚(PB0)是否高电平
- 检查电机驱动板供电
- 确认PWM引脚输出（PD12/13/14/15）

### 编码器无反馈
- 检查编码器供电（通常5V）
- 确认引脚连接正确
- 单独测试每个编码器

### 路径跟踪不准
- 校准物理参数（轮距、轮径、编码器PPR）
- 调整PID参数
- 增加IMU融合权重（如果航向漂移）
